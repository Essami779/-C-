===============================================
        دليل نظام إدارة الديون الشامل
===============================================

🎯 نظرة عامة على النظام:
------------------------
نظام إدارة الديون هو تطبيق Windows Forms متكامل لإدارة:
- بيانات العملاء والمنتجات
- المبيعات والديون
- المدفوعات والتسديدات
- التقارير والإحصائيات

🗄️ قاعدة البيانات:
------------------
النظام يستخدم SQL Server LocalDB مع الجداول التالية:

1. **جدول العملاء (Customers):**
   - CustomerID (المفتاح الأساسي)
   - CustomerName (اسم العميل)
   - Phone (رقم الهاتف)
   - CreatedDate (تاريخ الإنشاء)
   - IsActive (نشط/غير نشط)

2. **جدول المنتجات (Products):**
   - ProductID (المفتاح الأساسي)
   - ProductName (اسم المنتج)
   - Price (السعر)
   - CreatedDate (تاريخ الإنشاء)
   - IsActive (نشط/غير نشط)

3. **جدول المبيعات (Sales):**
   - SaleID (المفتاح الأساسي)
   - CustomerID (مرجع للعميل)
   - ProductID (مرجع للمنتج)
   - UnitPrice (سعر الوحدة)
   - Discount (الخصم)
   - TotalAmount (المبلغ الإجمالي)
   - PaidAmount (المبلغ المدفوع)
   - RemainingAmount (المبلغ المتبقي - محسوب تلقائياً)
   - SaleDate (تاريخ البيع)
   - Notes (ملاحظات)
   - IsCompleted (مكتمل/غير مكتمل)

4. **جدول المدفوعات (Payments):**
   - PaymentID (المفتاح الأساسي)
   - SaleID (مرجع للمبيعة)
   - PaymentAmount (مبلغ الدفعة)
   - PaymentDate (تاريخ الدفع)
   - PaymentMethod (طريقة الدفع)
   - Notes (ملاحظات)

🔧 الوظائف المتاحة:
-------------------

### 1. إضافة بيانات جديدة:
- أدخل اسم العميل ورقم الهاتف
- أدخل اسم المادة والسعر
- أدخل الخصم (اختياري)
- اضغط "إضافة" لحفظ البيانات

### 2. تعديل البيانات:
- اختر العنصر من القائمة
- اضغط "تعديل"
- عدّل البيانات المطلوبة
- اضغط "إضافة" لحفظ التعديلات

### 3. تسديد الديون:
- اختر العنصر من القائمة
- اضغط "تسديد"
- أدخل مبلغ الدفعة
- سيتم تحديث المبلغ المتبقي تلقائياً

### 4. البحث:
- استخدم مربع البحث للعثور على:
  * اسم العميل
  * رقم الهاتف
  * اسم المنتج

### 5. عرض البيانات:
- **الأخضر:** مدفوع بالكامل
- **الأصفر:** مدفوع جزئياً
- **الوردي:** غير مدفوع

### 6. تفاصيل الدفع:
- اختر العنصر واضغط "تفاصيل الدفع"
- عرض معلومات مفصلة عن المبيعة

### 7. تحديث البيانات:
- اضغط "كل البيانات" لتحديث القائمة
- عرض الإجمالي الحالي للديون

🎨 واجهة المستخدم:
------------------
- تصميم عربي كامل مع دعم RTL
- ألوان مميزة لحالات الدفع المختلفة
- رسائل تأكيد وأخطاء واضحة
- تنقل سهل بين الحقول

🔒 الأمان:
----------
- نظام تسجيل دخول آمن
- التحقق من صحة البيانات المدخلة
- معالجة الأخطاء بشكل آمن

📊 التقارير:
------------
- عرض إجمالي الديون
- تتبع المدفوعات
- تاريخ المبيعات
- حالة كل مبيعة

🚀 الميزات المستقبلية:
-----------------------
- طباعة التقارير
- ربط بالإنترنت
- نسخ احتياطي للبيانات
- استرداد البيانات

===============================================
        تعليمات التشغيل والإعداد
===============================================

📋 متطلبات النظام:
------------------
- Windows 7 أو أحدث
- .NET Framework 4.5.2 أو أحدث
- SQL Server LocalDB

🔧 إعداد قاعدة البيانات:
------------------------
1. تأكد من وجود SQL Server LocalDB
2. قم بتشغيل ملف Database_Schema.sql
3. تأكد من وجود ملفات Database.mdf و Database_log.ldf

🚀 تشغيل النظام:
----------------
1. شغل البرنامج
2. أدخل بيانات تسجيل الدخول:
   - اسم المستخدم: useradmin
   - كلمة المرور: admin123
3. ابدأ بإدخال البيانات

⚠️ نصائح مهمة:
---------------
- احتفظ بنسخة احتياطية من قاعدة البيانات
- تأكد من صحة البيانات قبل الحفظ
- استخدم البحث للعثور على البيانات بسرعة
- راقب الألوان لفهم حالة الدفع
