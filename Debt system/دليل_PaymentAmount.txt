===============================================
        دليل استخدام PaymentAmount في النظام
===============================================

💰 ما هو PaymentAmount؟
------------------------
PaymentAmount هو **مبلغ الدفعة** الذي يدفعه العميل في كل مرة يقوم بتسديد جزء من ديونه.

🔧 العمليات المتاحة لـ PaymentAmount:
---------------------------------------

### 1. إدراج دفعة جديدة:
```csharp
// في DatabaseManager.cs
public bool InsertPayment(int saleID, decimal paymentAmount, string paymentMethod, string notes)
```

**الميزات:**
- ✅ التحقق من أن المبلغ أكبر من صفر
- ✅ التحقق من أن المبلغ لا يتجاوز المبلغ المتبقي
- ✅ تحديث المبلغ المدفوع تلقائياً
- ✅ التحقق من اكتمال الدفع

### 2. حساب المبلغ المتبقي:
```csharp
// في DatabaseManager.cs
public decimal GetRemainingAmount(int saleID)
```

**الوظيفة:**
- حساب المبلغ المتبقي = الإجمالي - المدفوع

### 3. عرض تفاصيل المدفوعات:
```csharp
// في DatabaseManager.cs
public DataTable GetPaymentDetails(int saleID)
```

**يعرض:**
- جميع المدفوعات لمبيعة معينة
- تاريخ كل دفعة
- طريقة الدفع
- ملاحظات

### 4. إحصائيات المدفوعات:
```csharp
// في DatabaseManager.cs
public DataTable GetPaymentStatistics()
```

**يشمل:**
- إجمالي عدد المدفوعات
- إجمالي مبلغ المدفوعات
- متوسط مبلغ الدفعة
- تاريخ أول وآخر دفعة

🎨 واجهة تسديد الدفع:
---------------------

### فورم PaymentForm الجديد:
- **حقل مبلغ الدفعة:** إدخال المبلغ مع التحقق
- **طريقة الدفع:** قائمة منسدلة (نقدي، بطاقة ائتمان، تحويل بنكي، شيك، أخرى)
- **ملاحظات:** حقل نصي للملاحظات
- **أزرار سريعة:** "المبلغ كاملاً" و "نصف المبلغ"
- **عرض المبلغ المتبقي:** يتحدث تلقائياً

### الميزات الذكية:
- 🎯 **حساب تلقائي:** المبلغ المتبقي يتحدث فورياً
- 🎨 **ألوان مميزة:** 
  - أخضر: مدفوع بالكامل
  - برتقالي: مدفوع جزئياً
  - أحمر: غير مدفوع
- ⌨️ **اختصارات لوحة المفاتيح:** Enter للدخول
- ✅ **التحقق من صحة البيانات:** منع الأخطاء

📊 عرض البيانات:
----------------

### في ListView الرئيسي:
- **العمود المدفوع:** يعرض إجمالي PaymentAmount
- **العمود المتبقي:** يحسب تلقائياً
- **الألوان:**
  - 🟢 أخضر: مدفوع بالكامل (PaymentAmount = TotalAmount)
  - 🟡 أصفر: مدفوع جزئياً (PaymentAmount > 0)
  - 🔴 وردي: غير مدفوع (PaymentAmount = 0)

### في تفاصيل الدفع:
- عرض جميع المدفوعات مع:
  - رقم الدفعة
  - مبلغ الدفعة (PaymentAmount)
  - تاريخ الدفع
  - طريقة الدفع
  - ملاحظات

🔄 العمليات التلقائية:
---------------------

### عند إدراج دفعة جديدة:
1. **التحقق من صحة المبلغ**
2. **إدراج الدفعة في جدول Payments**
3. **تحديث PaidAmount في جدول Sales**
4. **التحقق من اكتمال الدفع**
5. **تحديث حالة المبيعة**

### عند حذف دفعة:
1. **حذف الدفعة من جدول Payments**
2. **تحديث PaidAmount في جدول Sales**
3. **إعادة حساب المبلغ المتبقي**

📈 التقارير والإحصائيات:
------------------------

### تقارير العملاء:
- إجمالي المدفوعات لكل عميل
- متوسط مبلغ الدفعة
- عدد المدفوعات

### تقارير المنتجات:
- إجمالي المدفوعات لكل منتج
- معدل السداد

### تقارير زمنية:
- المدفوعات اليومية/الشهرية/السنوية
- اتجاهات السداد

🔒 الأمان والتحقق:
-----------------

### التحقق من صحة البيانات:
- ✅ المبلغ أكبر من صفر
- ✅ المبلغ لا يتجاوز المبلغ المتبقي
- ✅ طريقة الدفع محددة
- ✅ رقم المبيعة صحيح

### معالجة الأخطاء:
- رسائل خطأ واضحة باللغة العربية
- منع إدخال بيانات غير صحيحة
- استعادة الحالة في حالة الخطأ

💡 نصائح للاستخدام:
-------------------

### للمستخدمين:
1. **استخدم الأزرار السريعة** لتسديد المبلغ كاملاً أو نصفه
2. **أضف ملاحظات** لتوضيح سبب الدفع
3. **اختر طريقة الدفع المناسبة** من القائمة
4. **راقب الألوان** لفهم حالة الدفع

### للمطورين:
1. **استخدم DatabaseManager** لجميع عمليات PaymentAmount
2. **تحقق من صحة البيانات** قبل الإدراج
3. **استخدم المعاملات** لضمان سلامة البيانات
4. **حدث الواجهة** بعد كل عملية

===============================================
        أمثلة عملية
===============================================

### مثال 1: تسديد دفعة جزئية
```
العميل: أحمد محمد
المادة: قميص
الإجمالي: 100 ريال
المدفوع: 0 ريال
المتبقي: 100 ريال

الدفعة الأولى:
- PaymentAmount: 30 ريال
- طريقة الدفع: نقدي
- ملاحظات: دفعة أولى

النتيجة:
- المدفوع: 30 ريال
- المتبقي: 70 ريال
```

### مثال 2: تسديد المبلغ كاملاً
```
العميل: فاطمة علي
المادة: حذاء
الإجمالي: 150 ريال
المدفوع: 0 ريال
المتبقي: 150 ريال

الدفعة:
- PaymentAmount: 150 ريال
- طريقة الدفع: بطاقة ائتمان
- ملاحظات: دفع كامل

النتيجة:
- المدفوع: 150 ريال
- المتبقي: 0 ريال
- الحالة: مكتمل ✅
```

### مثال 3: مدفوعات متعددة
```
العميل: محمد عبدالله
المادة: جاكيت
الإجمالي: 200 ريال

الدفعة الأولى:
- PaymentAmount: 50 ريال
- التاريخ: 2024-01-15

الدفعة الثانية:
- PaymentAmount: 75 ريال
- التاريخ: 2024-01-20

الدفعة الثالثة:
- PaymentAmount: 75 ريال
- التاريخ: 2024-01-25

النتيجة النهائية:
- إجمالي المدفوع: 200 ريال
- المتبقي: 0 ريال
- الحالة: مكتمل ✅
```
